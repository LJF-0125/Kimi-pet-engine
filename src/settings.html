桌宠设置

拖动滑块调整桌宠大小，即时生效、自动保存。

100%
启动

勾选后会自动往 ~/.kimi-code/config.toml 写入 SessionStart 钩子（取消则移除），之后每次 Kimi Code 开会话都会自动拉起桌宠。

检测到 kimi web 正在运行：钩子是进程启动时加载的，需重启 kimi web 后此变更才会生效。

隐藏

露出一条：贴边后留一小条在边缘；只露头：只留角色头部，可在下方框选头部区域。鼠标移上去即可唤回。

头框

在图上拖出一个框圈住角色头部；拖到屏幕边缘隐藏时将只露出这个区域。换 GIF 后需要重新框选。

为每种状态选一张透明底 GIF；未设置的状态会沿用「空闲中」的 GIF。
